# MCP Simple Server

Simple demo

## Installation

uv sync

## Claude configuration

claude mcp add notes-mcp -- uv run --directory $(pwd) server.py

## Blender Case

# Inside Blender - Scripting Workspace

1. Copy / Paste script *blender_server.py* script
2. Run it (Alt + P)

# Add MCP Server

Add MCP server to Claude : 

> claude mcp add blender-mcp -- uv run --directory /home/ali/Dev/Internal/mcp-simple blender_mcp_server.py
